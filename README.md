# Text Polish

文章を整えて、数えて、仕上げるためのブラウザツール。

Vanilla JS / CSS / HTML だけで動作し、入力した文章はブラウザ内で処理します。

## Features

### Character Count
- 文字数
- 目標文字数
- 残り文字数
- 進捗バー
- URL除外文字数
- 改行数
- 空白数
- 日本語文字数
- 英字数
- 数字数
- 記号数
- 絵文字数

### Text Polish
- 余分な空白を削除
- 連続した改行を整理
- 全角・半角を統一
- 句読点を統一
- 括弧・引用符を統一
- 前後の空白をトリミング
- URL抽出
- 箇条書き整形
- クリップボードへコピー

## Design

「入力 → 処理 → 確認 → コピー」という文章作業の流れを一画面にまとめています。

SNS投稿、ブログ、応募文、メモなど、文字数制限がある文章の仕上げに使えます。

## Run

静的サイトなので、index.html をブラウザで開くだけで動作します。

GitHub Pagesにもそのまま公開できます。

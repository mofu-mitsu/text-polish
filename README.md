# Text Polish

文章を**整えて、数えて、変換して、仕上げる**ブラウザ完結型のテキストワークベンチ。

## Features

### 文字数・SNS
- 改行・空白込みの文字数
- 改行・空白を除外した文字数
- URL除外文字数
- 改行 / 空白 / 日本語 / 英字 / 数字 / 記号 / 絵文字
- 目標文字数と進捗バー
- SNSモード：X 280 / X日本語目安140 / X Premium長文25,000 / Bluesky 300 / Instagram 2,200 / Threads 500

### 文章整形
- 空白整理
- 改行整理（全削除 / 連続改行整理 / 空白行削除 / 空行整理 / 1文字ずつ改行）
- 全角・半角整理
- URLを保護した句読点統一
- 引用符整理
- 全行の行頭・行末トリミング
- 箇条書きの「*」「-」などを「・」へ統一
- 各行への「・」追加

### 変換・置換
- ひらがな ⇔ 全角カタカナ
- 全角カタカナ ⇔ 半角カタカナ
- 英字の大文字 / 小文字
- 数字の全角 / 半角
- 記号の全角 / 半角
- 通常の文字列置換
- JavaScript正規表現による置換

### 入出力・履歴
- TXT / Markdown / CSV の読み込み
- TXT保存
- Undo / Redo
- クリップボードコピー

## Privacy

入力内容はサーバーへ送信せず、ブラウザ内のJavaScriptだけで処理します。

## Tech

- HTML
- CSS
- Vanilla JavaScript

GitHub Pagesなどの静的ホスティングでそのまま動作します。


### ワークベンチUI
- 左側のクイックツールバーから編集 / 範囲 / 整形 / 分割 / 変換へ移動
- テキストエリアでドラッグ・Shift選択した範囲だけを処理する範囲選択ツール
- よく使う変換をワンクリック実行（* → ・ / - → ・ / + → ・ / 文ごとに改行など）
- 文末の「。！？!?」を基準に文ごとに改行

### SNS投稿分割
- 任意の文字数（初期値140）で投稿単位に分割
- 「文の途中で切らない」モード
- 本文を変更せず、投稿ごとのプレビューを生成
- 各投稿を個別にコピー


### 範囲選択ワークフロー
- 範囲選択中は、整形・改行・句読点・引用符・全角半角・箇条書き・かな・英字・数字・記号変換を選択範囲だけに適用
- 選択範囲を保ったまま加工し、加工後も変換後の範囲を再選択
- 置換・正規表現置換も選択範囲を優先

### フローティングクイックツール
- SVGアイコンのクイックツールバー
- ドラッグして好きな位置へ移動
- 位置をブラウザに保存
- 「‹ / ›」で折りたたみ
- PCはカーソルを合わせると詳細、タッチ端末は長押しで詳細表示

### SNS投稿エディター
- SNS分割を独立した編集ワークスペースとして搭載
- 文字数＋文境界 / 改行優先 / 改行ごとの手動分割
- POST 1 / POST 2…を個別のテキストエリアで編集
- 投稿の追加・削除
- 投稿カードをドラッグして並べ替え
- 投稿ごとの文字数表示と個別コピー
- 編集した投稿列を本文へ反映
